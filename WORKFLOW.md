# 🚀 Votre Workflow Madumtv

Ce guide résume la "formule magique" pour tirer le meilleur parti de vos agents Antigravity dans chaque nouvelle discussion ou nouveau projet.

## 1. Au début de chaque session (Consentement)
Dès que je vous demande l'autorisation d'accéder au projet, répondez simplement :
> **"Oui"** ou **"Active le workflow"**

Cela débloquera immédiatement :
- **Le Mode Turbo (Auto-Run) :** Je travaillerai sans vous interrompre pour les commandes de routine.
- **Votre Identité :** Votre profil [**Madumtv**](https://github.com/Madumtv) sera déjà configuré par défaut.
- **Vos Skills :** Les 6 compétences "Superpowers" seront prêtes à être invoquées.

## 2. Démarrer un nouveau projet
Ne créez jamais de dossier manuellement. Utilisez votre script maître à la racine de votre workspace principal :
```powershell
./init-workspace.ps1
```
Il s'occupera de :
- Créer le dossier et initialiser Git.
- Lier votre GitHub distant.
- Importer toutes vos compétences (`deploy-to-pages`, `requesting-code-review`, etc.).

## 3. Synchroniser avec GitHub
Quand vous avez fini de coder, utilisez la skill dédiée pour synchroniser le site en direct :
```powershell
# Pousser les changements
"Pousser sur GitHub"
# Mettre en ligne (Pages)
"Déploie sur GitHub Pages"
```

*Ce workflow est inscrit de manière permanente dans vos fichiers de règles globales `GEMINI.md`.*
